
The SLM module relies on the Reporting module to manage and show the reports.
Therefore, user permissions for creating, modifying and visualizing the reports should be granted
within the Reporting section in :menuselection:`Configuration / Access Control / Roles`.
This is the list of available permissions that can be used to extend the range of
available actions for a specific user:

* **Full Module Access**: gives unlimited access on the Reporting module.
* **General Module Access**: allows to access the reports in *read-only* mode.
* **reporting/reports**: allows to manage the reports.
* **reporting/schedules**: allows to manage the report scheduled actions.
* **reporting/templates**: allows to manage the report templates.
* **reporting/timeframes**: allows to manage the report timeframes.
