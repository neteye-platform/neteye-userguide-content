Backup and Restore
------------------

It is strongly recommended to regularly back up your NetEye configuration and data to prevent data loss and ensure quick recovery in case of system failures or other issues.

For the |ne| Master, you can use the built-in backup and restore functionalities, for the supported services,
to easily backup and eventually restore your configuration and data on a supported backup provider.

For more details, please refer to the :ref:`Backup and Restore <backup-restore>` section.
