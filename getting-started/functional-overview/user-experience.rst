User Experience
~~~~~~~~~~~~~~~

Monitoring of the real user data can prove useful for optimizing your web performance and thus, providing exceptional user experiences.
You can monitor the real user experience and interaction within your client-side application to discover performance issues.
With the help of synthetic monitoring you can also run and measure your business-critical workflows like a human would, but continuously.

**Alyvix**

Integration with :ref:`Alyvix <visual-monitoring-alyvix>` allows you to visually monitor any
Windows application (for example ERPs) and any web app, through NetEye's User Interface,
continuously measuring workflows like a human user would do.

For more information, please consult `Alyvix official documentation <https://alyvix.com/learn/introduction.html>`__.

**Elastic RUM**

`Real User Monitoring <https://www.elastic.co/guide/en/observability/current/apm-rum.html>`__ captures user interaction
with clients such as web browsers.
Measuring certain metrics will help you discover performance issues within your client-side application
as well as issues that relate to the latency of your server-side application.

Elastic RUM feature is available for NetEye installations with the :ref:`Elastic Stack feature module <elastic-feature-module>`.
