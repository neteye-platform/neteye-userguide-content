.. _nagvis-overview:

Product Overview
~~~~~~~~~~~~~~~~

The module presents integration with the NagVis visualization tool for the information
which is gathered by Icinga2 and transferred using backends.

Using data supplied by a backend NagVis will update objects placed on maps in certain intervals to reflect the current state. These maps allow to arrange the objects to display them in different layouts:

- physical (e.g. all hosts in a rack/room/department)
- logical (e.g. all application servers)
- geographical (e.g. all hosts in a country)
- business processes (e.g. all hosts/services involved in a process)

Please consult official `NagVis documentation <https://www.nagvis.org/about>`__ in order to find all the operational details for the software.
