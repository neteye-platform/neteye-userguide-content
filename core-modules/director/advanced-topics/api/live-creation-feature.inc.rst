
Icinga Director Live-Creation
`````````````````````````````

The Icinga Director “Live-Creation” **experimental** feature permits to
create Icinga Objects in the Director and simultaneously also directly
in Icinga2, without the need to deploy the Director configuration.

The Live-Creation is available both from icingacli and from the Director
REST API.

Below you see a flowchart which gives you an idea of what happens when
the Object Live-Creation is called from the Director REST API.
