Machine Learning Overview Page
------------------------------

The Machine Learning Overview page is the main access point to the
**machine learning capabilities** available in Kibana. It is the landing
page of the Machine Learning area and helps you get to the right
capability for your goal, whether you want to detect anomalies,
statistically analyze data, explore logs or work with trained models.

The page is organized into functional areas. Each area contains action
buttons that start a specific type of analysis.

.. figure:: /neteye-cloud/elk/analytics/img/machine-learning-overview.png
   :alt: Machine Learning Overview Page
   :align: center

Analyze your data
   The main starting point for applying machine learning to your data.
   From here you can access anomaly detection in order to find unusual behavior,
   and data frame analytics in order to run trained analyses on datasets.

AIOps Labs
   Advanced analysis tools for operational investigations. Use them to
   find significant changes in log volume, recurring log patterns or
   shifts in metric behavior during troubleshooting and root cause
   analysis.

Visualize your data
   Data exploration and preparation. Use it to inspect, query, compare
   or upload data before you start a deeper analysis.

Management and documentation
   Quick access to management and support functions: ML asset
   administration, trained model management and the official
   documentation.

.. tip::

   If you are not sure where to start, explore your data in
   :guilabel:`Visualize your data` first. Then move to :guilabel:`Analyze your data` for
   continuous analysis, or to :guilabel:`AIOps Labs` for on-demand investigation.
