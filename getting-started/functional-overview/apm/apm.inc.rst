
Application Performance Monitoring
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Elastic APM (Application Performance Monitoring) is a feature that
allows you to collect data about the performance of applications and monitor
them in real time, with the goal of quickly pinpointing problems
and applying fixes in your applications.

For more information you can have a look at the
`Elastic official documentation <https://www.elastic.co/guide/en/observability/master/apm.html>`__,
or check out |ne|'s :ref:`Elastic Stack feature module <elastic-feature-module>` to learn more about Elastic APM.
