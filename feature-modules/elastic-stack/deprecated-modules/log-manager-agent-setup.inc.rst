Agents Setup for NetEye Syslog Auditing
---------------------------------------

The Safed Agent must be installed on each remote machine that will need
to send logs to NetEye. The Safed Agent can be installed on Windows and
Linux (v1\_10\_1), as well as AIX and HP-UX (v1\_8\_3).

This PDF document describes the `Safed Agent installation procedure <https://github.com/WuerthPhoenix/safed/blob/master/doc/Safed_installation.pdf>`_ for
each operating system (for Windows, see below).

The full Safed Agent project on GitHub can be found `in the project
home page <https://github.com/WuerthPhoenix/safed>`_.

A Windows pre-compiled binary can be found on the NetEye download page
by following the path **NetEye > SAFED > Windows msi**. The most
up-to-date installation instructions for Windows can be found `in pdf
version
<https://github.com/WuerthPhoenix/safed/blob/master/doc/safedInstallationWin.pdf>`
(remember to install with Administrator rights).
