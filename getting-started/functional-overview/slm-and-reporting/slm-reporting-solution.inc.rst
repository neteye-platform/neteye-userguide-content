
Service Level Management & Reporting
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

An important part of any technology vendor contract is to define
the level of service expected from the vendor, laying out metrics by which service is measured,
as well as consequences in case the service levels weren't achieved.

With |ne|'s SLM (:ref:`monitor-slm`) module you can create definitions of the contracts
for which you can calculate metrics like availability over a set of monitored objects (e.g., hosts and services).

Data about availability and resource consumption that are produced by |ne|'s monitoring features
can be used to automatically generate various types of reports that show the past behaviour of services, hosts,
and systems controlled by |ne|.

|ne| provides a complete reporting solution, the :ref:`Reporting Module <reporting-module>`, that can be used to create reports,
tailored for each customer and contract, and build a notification system that will inform you
in case some event takes place within the infrastructure.
