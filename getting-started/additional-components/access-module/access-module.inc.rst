Accessing the New Module
------------------------

If the procedure you followed above was successful, you can now access
the new module with these steps:

* Refresh your browser window.  This will ensure that the new module
  appears in the |ne| menu and all Javascript and CSS is reloaded
  properly.
* Log out of |ne| and then log back in so that any :ref:`permissions
  or roles <roles-users-permissions>` required by the new module will
  take effect.
