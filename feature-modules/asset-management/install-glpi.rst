Installation
------------

To install the Asset Management module, perform neteye-asset additional component installation by means
of following steps in :ref:`additional modules <neteye-install-modules>` guide; the
**Asset** menu item will then appear in the left side navigation menu.
The module can be configured for:

*   :ref:`glpi-configuration-singletenancy`
*   :ref:`glpi-configuration-multitenancy`
