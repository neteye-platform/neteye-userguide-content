
.. _alyvix-overview:

Overview
--------

Alyvix monitoring system within NetEye is not included in the NetEye Core,
and is to be additionally installed as a Feature Module.

In order to start using Alyvix within NetEye, follow the procedure described
in :ref:`neteye-components`.

After the Alyvix Feature Module has been installed, it is possible to configure
an Alyvix node in NetEye to be able to monitor and configure it from the NetEye UI in just
a few steps that you will find below.

Alyvix Service is available under its own product license. You can find out
more on how to obtain Alyvix license in its `installation guide <https://alyvix.com/learn/service/install.html#installation-steps>`_.
