
IT Operations
~~~~~~~~~~~~~

IT Operations, also known as :ref:`Command Orchestrator Module <command-orchestrator>`, allows to execute predefined commands on remote hosts.
Executing predefined commands (also remotely) on hosts without having access to them can be very useful in many situations.
For example, a first level support agent using |ne| may need to restart a Windows service on a Windows host without access to it.

You can use the various command options with the Command Orchestrator to achieve specific results.

The Command Orchestrator module lets the |ne| admin define Commands and Groups of Commands that can be assigned to other non-admin |ne| users,
who will then be able to execute them through the Command Orchestrator module itself.
