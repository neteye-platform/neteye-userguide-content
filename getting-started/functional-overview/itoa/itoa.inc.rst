
IT Operation Analytics
~~~~~~~~~~~~~~~~~~~~~~

IT Operation Analytics is a popular method that allows you to gather various types of data
from an IT infrastructure and analyze it according to some user-defined metrics,
with the primary purpose of recognizing patterns and behavior.

The outcome allows IT managers to prevent bottlenecks, optimize, and plan improvements
to the infrastructure.

In the process of monitoring with |ne|, the IT Operation Analytics allows users to view
various types of data collected by |ne| during its monitoring activities
and show them on the dashboards for a quicker analysis.

The :ref:`IT Operations Analytics <itoa-module-description>` module complements monitoring functionalities by collecting
telemetry data from network traffic, as well as from systems and applications.
Complex events can be processed to find correlations or cause-effect relations.

ITOA adds IoT and IIoT abilities to |ne|'s monitoring features.
