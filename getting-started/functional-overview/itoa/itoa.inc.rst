
IT Operation Analytics
~~~~~~~~~~~~~~~~~~~~~~

IT Operations Analytics is a popular method that allows to gather various types of data
from an IT infrastructure and analyze them according to some user-defined metrics,
with the primary purposes to recognise patterns and behaviors.

The outcome allows IT managers to prevent bottlenecks, optimize and plan improvements
to the infrastructure.

In the process of monitoring with NetEye, the IT Operation Analytics allows users to view
various types of data collected by NetEye during its monitoring activities
and show them on the dashboards for a quicker analysis.

The :ref:`IT Operations Analytics <itoa-module-description>` module complements monitoring functionalities by collecting
telemetry data from network traffic and from systems and applications.
Complex events can be processed to find correlations or cause-effect relations.

ITOA adds IoT and IIoT abilities to NetEye's monitoring features.
