
When monitoring your infrastructure, utilizing and automating the process of data visualization
proves to be a significant boost in analysis efficiency, and helps you easily obtain insights
into the state of your infrastructure.

With that in mind, |ne| offers a set of tools for visualizing your data.
This includes both internally developed solutions, like dashboards or monitoring overviews or maps,
and integrated software, e.g. Nagvis.

The :ref:`monitor-visual-dashboard` can be defined and customized to show the real time status
of your infrastructure.

If you want to quickly check the monitoring status, :ref:`monitoringview-module` will give you all the
relevant information about your hosts and services, groups, and even scheduled downtimes.
On top of that, you can also customize your monitoring view to reflect only the problems detected.

The :ref:`Geo Map module <geomap-visualizer>` lets you monitor the geographical location of your hosts,
overlaid on maps from the OpenStreetMap open source initiative.
All the standard map interface tools are there, such as zooming, panning, and markers.
Markers are linked directly to monitoring views.

Integration with :ref:`NagVis <nagvis-overview>` allows you to use overlaid maps to graphically see which network channels
are operating within parameters for those organizations that have multiple physical locations.

With the help of NagVis integration you can display single Hosts and Services,
or the summary state of a Host and all its services.
It also allows you to visualize complete IT processes using self-drawn graphics.
