
Network Visibility
~~~~~~~~~~~~~~~~~~

The monitoring experience with NetEye provides network visibility, allowing it to check,
monitor, and store data about the traffic flowing through NetEye.

These functionalities are provided by ntopng software, which seamlessly integrates within NetEye.
It provides an intuitive, encrypted web user interface for the exploration of realtime and historical traffic information.

ntopng is available as a Feature module that can be accessed using Single Sign On.

Please see :ref:`monitor-network-conf` for more details.
