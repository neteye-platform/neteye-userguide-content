
Service Level Management & Reporting
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

An important part of any technology vendor contracting is to define
the level of service expected from a vendor, laying out metrics by which service is measured,
as well as consequences in the case service levels weren't achieved.

With NetEye's SLM (:ref:`monitor-slm`) module you can create definitions of the contracts
for which you can calculate metrics like availability over a set of monitored objects (e.g., hosts and services).

Data about availability and resource consumption that are produced by NetEye's monitoring features
can be used to automatically produce various types of reports that show the past behaviour of services, hosts,
and systems controlled by NetEye.

NetEye provides a complete reporting solution, :ref:`the Reporting Module <reporting-module>`, that can be used to create reports,
tailored for each customer and contract, and build a notification system that will inform you
in case some event takes place within the infrastructure.
