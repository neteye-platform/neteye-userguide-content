
Network Visibility
~~~~~~~~~~~~~~~~~~

The monitoring experience with |ne| provides network visibility, allowing it to check,
monitor, and store data about the traffic flowing through |ne|.

These functionalities are provided by the ntopng software, which seamlessly integrates within |ne|.
It provides an intuitive, encrypted web user interface for the exploration of real-time and historical traffic information.

ntopng is available as a Feature module that can be accessed using Single Sign-On.

Please see :ref:`monitor-network-conf` for more details.
