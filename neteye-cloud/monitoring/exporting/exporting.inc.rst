Exporting Monitoring Data
~~~~~~~~~~~~~~~~~~~~~~~~~

Once you've completed a search, you can export the hosts that matched the
filter into various formats.

Hover on the down arrow icon at the top of the panel and then select one
of the file formats as shown below.
